## **📊 POWER BI DASHBOARD ROADMAP**

### **Phase 1: Data Connection (15 mins)**
1. Open Power BI Desktop
2. Connect to PostgreSQL database (local or Aiven)
3. Import 4 tables: customers, products, sales, inventory
4. Verify data loaded correctly

### **Phase 2: Data Modeling (10 mins)**
1. Go to Model view
2. Create relationships:
   - **customers** ←→ **sales** (customer_id)
   - **products** ←→ **sales** (product_id)
   - **products** ←→ **inventory** (product_id)
3. Set relationship type: One-to-Many
4. Verify relationships active

### **Phase 3: Create Measures (15 mins)**
Create DAX measures:
- **Total Sales Revenue** = SUM(sales[total_amount])
- **Total Quantity Sold** = SUM(sales[quantity_sold])
- **Total Customers** = DISTINCTCOUNT(sales[customer_id])
- **Total Products** = DISTINCTCOUNT(sales[product_id])
- **Average Order Value** = [Total Sales Revenue] / [Total Transactions]
- **Total Transactions** = COUNTROWS(sales)
- **Low Stock Products** = COUNTROWS(FILTER(inventory, stock_quantity < 10))

### **Phase 4: Build Dashboard Visuals (45 mins)**

**A. Sales Performance Section**
1. **Card Visual**: Total Revenue
2. **Card Visual**: Total Transactions
3. **Card Visual**: Average Order Value
4. **Line Chart**: Sales Trend Over Time (sale_date on X-axis, total_amount on Y-axis)
5. **Column Chart**: Monthly Sales Comparison

**B. Product Performance Section**
1. **Table**: Top 10 Products by Revenue (product_name, total_sales, quantity_sold)
2. **Bar Chart**: Sales by Category (category vs total_amount)
3. **Scatter Plot**: Price vs Quantity Sold
4. **Pie Chart**: Revenue Distribution by Category

**C. Customer Insights Section**
1. **Card**: Total Unique Customers
2. **Table**: Top 10 Customers by Spending (customer_name, total_spent, purchase_count)
3. **Bar Chart**: Customers by Membership Status
4. **Histogram**: Customer Purchase Frequency Distribution

**D. Inventory Insights Section**
1. **Card**: Total Products in Stock
2. **Card**: Low Stock Alert (products with stock < 10)
3. **Table**: Products Needing Restock (product_name, stock_quantity, total_sold)
4. **Bar Chart**: Stock Quantity by Category
5. **Gauge Chart**: Inventory Health (average stock level)

### **Phase 5: Formatting & Polish (15 mins)**
1. Add dashboard title
2. Arrange visuals in logical layout
3. Apply consistent color scheme
4. Add slicers:
   - Date Range slicer
   - Category slicer
   - Membership Status slicer
5. Format numbers (currency, decimals)
6. Add tooltips
7. Test interactivity between visuals

### **Phase 6: Final Review (10 mins)**
1. Verify all relationships working
2. Check data accuracy
3. Test filters and slicers
4. Ensure mobile-friendly layout
5. Save and publish
